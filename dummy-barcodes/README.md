# Dummy barcodes

Eight scannable EAN-13 barcodes for testing the vendor console's **Inventory
→ Scan barcode** feature, generated by [generate.js](generate.js) (no
dependencies — implements EAN-13 encoding directly, with a checksum
self-test against two known-good real-world codes).

## Use them

- Open [index.html](index.html) in a browser and print it, or point a phone
  camera at your screen.
- Or open any individual `.svg` file and scan/photograph it directly.
- In the vendor console, go to **Inventory → Scan barcode**. If the camera
  isn't available (or you're testing headlessly), type the 13-digit code
  from under the bars into the "or type it" field instead — same lookup
  path either way.

## Regenerating

```bash
node generate.js
```

Edit the `DUMMY` array at the bottom of `generate.js` to change how many
codes are generated or their labels — each is built from a 12-digit prefix
with a correctly computed 13th check digit, so codes stay valid EAN-13s.

These are **not** real registered product barcodes — the prefix
(`890103082...`) is arbitrary, chosen only to keep every generated code
looking similar and be obviously a fixture.
